# Shopcity 广告控制器 · 桌面版

这个仓库用于发布 Windows 桌面版安装包、更新文件和版本说明。开发项目在独立私有仓库维护。

## v1.5.15 广告明细修改预算

- 「广告明细」右键新增「修改预算」。弹窗重新读取广告当前所属广告组或广告系列，展示预算原币、日预算／总预算、实际修改对象、读取时间和金额变化预览，并明确提示共享预算的影响范围。
- 仅修改现有预算金额。按你输入并确认的金额直接覆盖，不因后台金额变化再次确认；预算归属、币种或类型变化，以及原币金额不明、归属不明确或读取不完整时，会提示原因，不误改其他对象。不使用美元换算值提交原币预算，不增加写死的额外金额上限。
- 支持任务运行期间修改，沿用串行操作和当前店铺、账户、登录及操作模式校验。保存期间显示加载遮罩，阻止重复点击；成功后回读预算核验，失败保留编辑内容并支持重新读取。
- 提交前持久化修改请求。超时先回读核实，同一共享预算有待核验修改时不重复提交；重启后记录保留，后续预算采集可继续核验。旧的后台预算响应不能覆盖已修改的新金额。
- 「广告操作日志」记录修改前、目标及核验后预算、币种、类型、预算归属和所属对象，并提供独立的「预算已核验」字段。预算核验不会冒充广告状态核验；失败或待核验同时记录异常，其他广告继续控制。
- 修改预算不直接开关广告，不改变规则绑定、手动接管、复核次数或执行间隔。仅更新当前日期的相关预算信息及缓存，保留历史记录、原始数据、统计次数和视图；恢复备份时保留较新的预算修改记录，避免重复提交。

升级保留现有数据、配置、规则绑定、视图、目录、登录状态及运行意图。可在软件内「软件更新」检查新版；安装前退出其他店铺实例。首次使用请在「广告明细」的广告数据行右键选择「修改预算」，预算修改需处于操作模式。

## v1.5.14 广告明细预算展示

- 「广告明细」补齐预算、预算类型、预算归属，并提供预算币种、所属广告组或广告系列、采集时间和数据状态等可选字段。金额显示明确币种，缺失显示「未获取」，保留旧值时显示「上次采集」。
- 新默认视图在广告花费前显示预算三列；已有视图保持原配置。在「字段配置」搜索「预算」，即可像其他字段一样显示或隐藏并自动保存，保留其他列的顺序、宽度、冻结、筛选和排序，不增加专用按钮。
- 广告级报表未提供预算时，使用原报表接口按账户批量读取广告组、广告系列预算，并按实际所属对象匹配。每个店铺实例使用独立后台队列和本地缓存，不逐条广告请求；广告暂停、复核和主任务完成不等待预算请求。
- 预算缓存及失败重试间隔为 15 分钟，过期后随下一次相关采集补充。预算获取失败会保留有效旧值、记录异常并继续其他账户，停止、关闭或跨天时不提交过期补充结果。
- 优先使用明确的 USD 预算，否则保留原金额及其币种；不将缺失值认作预算 0，也不猜测未知预算类型或归属。共享预算不按广告行重复求和或平均，避免同一笔广告组、广告系列预算被多次累加。
- 升级补齐本地预算字段和缓存，分批恢复历史记录中已有的预算信息，保留原始数据、记录时间和次数、已保存视图及旧预算值。预算补充只更新对应记录的预算信息，不改变广告状态、控制规则、复核次数或检查间隔。

升级保留现有数据、配置、规则绑定、视图、目录、登录状态及运行意图。可在软件内「软件更新」检查新版；安装前退出其他店铺实例。已有记录缺少预算时，将随后续正常采集在后台补充。

## v1.5.13 定时开启重排、访客 CPC 与中文输入修复

- 「定时开启」统一为定时开启规则列表，固定展示启用、规则名称、广告账户范围、控制规则、开启时间、操作六列。取消页面总开关，由各条规则独立控制；胶囊开关点击后需要确认，保存期间显示遮罩并阻止重复操作，失败后保留原状态。
- 新增、编辑和复制改为弹窗，分区整理名称、开启时间、账户范围、控制规则、广告条件及检查窗口/重试设置。新增和复制的规则默认停用，保存后可从列表启用；取消编辑不覆盖已保存内容。
- 开启时间可单选「账户时区」（默认）或「北京时间」。规则每天执行，移除执行星期、最近规则执行记录和主任务时区比较面板；北京时间只改变触发时刻，花费判断、状态核验和每日广告去重仍按各账户当地当天处理，历史操作记录保留。
- 升级保留原有定时规则；原总开关关闭时，各条规则继续停用。支持运行中编辑保存，下一次相关检查生效；单条规则保存不会覆盖其他规则，并拦截过期编辑。保留白名单、观察规则、手动接管、单广告定时开关、待核验隔离和既有检查间隔。
- 「广告明细」新增可选数值字段「访客CPC」，按本地已保存的 USD 花费 ÷ 店铺访客数计算，默认位于 CPC 后。支持字段显隐、筛选、排序、分组、汇总和导出；访客为零、缺失或无效时留空。历史数据可直接计算，无需重新采集。
- 修复「控制规则 → 今日绑定广告」搜索框打断拼音输入的问题。组字选字期间不发起搜索，确认后再查询；后台刷新、旧请求和查询失败保留输入框与光标，避免输入中断。

## v1.5.12 按控制规则定时开启

- 定时开启计划新增“适用控制规则”，支持搜索和多选。可设置使用“通用规则”的广告在账户当地 06:00 开启，使用“加购规则”的广告在当地 00:00 开启。
- 控制规则范围与账户范围、原有广告筛选条件同时满足。未单独指定规则的广告按通用规则匹配；规则更名不会丢失关联。此范围只选择参加计划的广告，不要求先通过控制规则的花费检查点。
- 增加计划范围可能重叠的提示，提醒检查旧的“不限控制规则”计划。保留同一广告在账户当地当天的去重和待核验隔离，不因换规则、调整计划或重启而重复开启。
- 匹配预览只读取本地最近完成的账户当地当天采集，展示广告当前规则、当地开启时间、数据时间及不匹配或跳过原因，不额外请求广告接口。
- 被定时计划引用的控制规则暂不可删除或改为观察规则，明确显示引用的计划名称；保存计划与删除规则同时发生时也会检查关联。
- 支持运行中编辑保存，从下一次相关检查起生效，当前批次保留原配置。白名单、观察规则、手动接管和单条广告的定时开启开关继续优先生效。
- 旧计划继续保持原有范围和当天完成记录。若关联规则异常失效，只记录并跳过相关计划，不影响其他计划和主任务继续执行。

## v1.5.11 今日绑定广告统计与列表

## v1.5.10 定时开启巡检与待核验处理修复

- 修复定时开启后，因少数广告仍待核验，导致整个账户在检查窗口内每分钟重复读取、保存数据和记录定时检查的问题。
- 完整扫描并提交定时开启请求后，待核验广告交给正常主任务继续核验；相同账户、日期及时区的数据读取会复用。正常广告检查继续遵守选择的执行间隔。
- 待核验结果仍如实显示，不标为开启成功，不重复发送开启请求；已卡住的旧定时开启记录也可接续处理，重启后保留处理进度。
- 保留未发送候选、取消、窗口结束、数据异常及其他操作阻挡时的处理约束；相互独立的定时规则分别完成，不被无关待核验记录拖住。
- 保留连续五次完整报表未找到后的归档、白名单、规则、复核次数及广告操作核验机制。

## v1.5.8 绑定广告指标与访客 CPC

- 「控制规则 → 绑定广告」显示当前规则花费检查点中启用的指标；跨检查点和条件组自动合并去重，花费始终显示。读取各广告最近一次本地记录，并标明数据日期、有效采集时间及异常数据沿用情况。
- 新增「访客 CPC 上限」，按 USD 花费 ÷ Shopcity 访客数计算，与原有 CPC 分开使用。支持通用规则、自定义规则及暂停复核，按完整精度比较，等于上限可通过。
- 新指标默认关闭，0 或留空不启用；零访客、访客数据缺失或无效时，按现有 CPC 逻辑暂缓判断，不算成 0，也不因此消耗暂停复核次数。升级保留旧规则及已有复核记录。
- 绑定列表新增「投放状态」：投放中显示绿色，已关闭显示红色；前四个数据列调整为「广告账户 ID、广告、投放状态、花费」。状态来自最近一次本地采集，不额外请求后台。
- 增加刷新本地数据，保留搜索、批量更换规则、横向滚动和左侧广告身份列。金额显示两位小数，悬停查看完整精度；缺失值显示“—”。
- 优化当前页广告最近记录的索引查询，避免全量扫描历史；日志保留访客 CPC 的计算输入、结果和上限，便于核对判断依据。

- 新实例首次打开时分别选择数据和备份位置，再自行登录、选择账户和运行；规则从默认设置开始。
- 窗口标题、顶部名称和托盘菜单区分店铺；停止或退出一个实例不影响其他店铺。同一店铺不能由多个实例同时运行。
- 重复打开同一实例会唤起已有窗口。升级后仍需手动运行任务。

## v1.0.6 自定义存储与目录迁移

- 首次启动可分别选择数据目录和备份目录；已有安装继续使用原位置，安装更新不会自动迁移数据。
- 在“数据与设置 → 存储位置”中，停止任务后可分别迁移数据或备份，也可同时迁移。
- 迁移会检查路径、权限及磁盘空间，复制并校验数据库全部表记录、设置和备份文件，全部通过后才切换位置并重新打开软件。
- 原数据库及备份会保留，目标目录已有文件不会被覆盖；目录不可访问时提供找回原数据位置入口。
- 登录会话、加密密码和位置记录继续保存在原应用目录，请保留该应用目录。迁移后仍需手动点击“运行”。

## v1.0.5 视图与白名单改进

- 白名单支持运行中新增、删除、批量删除、撤销和修改备注，保存后下一轮生效。
- 字段显隐、顺序、列宽、冻结和行高按表格及视图独立自动保存，筛选日期、分页和重新打开后保留。
- 每张表只保留一个内置默认视图，自建视图保留且可删除；默认视图也能保存筛选、排序、分组、着色和汇总。
- 在“视图配置”中重命名默认或自建视图，保留原有配置；升级时继承最近保存的旧内置视图字段配置。
- 更新保留本机数据库、规则、视图、账户选择与加密登录设置；更新后仍需手动点击“运行”。

## 主要功能

- 独立桌面运行，支持多个独立店铺实例，每个店铺可管理多个广告账户。
- 观察／操作模式，持续执行广告保护、暂停复核和可选的账户当地时间定时开启。
- 广告明细、账户汇总、操作日志和异常日志采用本地表格，支持独立视图、筛选、排序、分组、冻结、汇总和完整 CSV 导出。
- 支持托盘常驻、断网恢复、可选本地加密自动登录，以及手动／每日自动备份。
- v1.1.9 启动的任务可在重新打开对应实例后自动恢复，主动停止则不恢复。迁移或恢复备份前仍需停止任务，完成后手动运行。

## 首次安装

从 [最新正式版本](https://github.com/harmony-s/sc-fb-desktop/releases/latest) 下载 `ShopcityControllerSetup.exe`，关闭旧版后安装。

安装包链接：[下载 Windows 安装包](https://github.com/harmony-s/sc-fb-desktop/releases/latest/download/ShopcityControllerSetup.exe)。

## 后续更新

在软件左侧打开“软件更新”，检查并下载新版本，然后点击“重启安装更新”。软件也会在后台定期检查新版本。

重启安装前会停止广告任务，完成已发送请求的核验。本地数据库、规则、视图和登录会话会保留。更新后会重新打开发起更新的店铺实例，并恢复更新前仍在运行的任务。

多个店铺实例共用一个软件版本。v1.1.0 起，安装更新前需先退出其他实例。关闭窗口可能只是收起到托盘，请从其托盘菜单选择“退出当前实例”。当前实例会保存设置并完成升级前备份，再安装更新。

v0.10.0 及更早版本没有内置更新入口，需要先手动安装一次带更新功能的版本。

## 发布文件

- `ShopcityControllerSetup.exe`：首次安装或手动更新。
- `RELEASES` 和 `XHShopcityController-<版本>-full.nupkg`：软件内置更新使用。
- `SHA256SUMS.txt`：发布文件校验值。

这些文件随 GitHub Release 提供，不存入 Git 文件历史。此仓库不存放使用者的本地广告数据库、登录信息或个人配置。
