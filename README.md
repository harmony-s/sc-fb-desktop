# Shopcity 广告控制器 · 桌面版

这个仓库用于发布 Windows 桌面版安装包、更新文件和版本说明。开发项目在独立私有仓库维护。

## v1.1.8 账户选择自动保存

- 运行中可以重新检测和修改广告账户，勾选和取消勾选自动保存，从下一轮生效。
- 修复多行粘贴账户 ID 和不同字符格式的匹配，进度刷新与重新检测保留最新勾选。
- 全部取消后保存为空范围，重启后也会保留。界面显示保存状态，失败时可重试。

## v1.1.7 删除店铺实例

- 在「管理 → 店铺实例」可删除已退出的非默认实例，收在托盘里的实例需先退出。
- 删除时默认保留本地数据。取消勾选后，实例的当前数据库、设置、登录资料和可识别的备份会移至回收站。

## v1.1.6 视图自动保存

- 各报表的筛选、搜索、排序、分组、着色和汇总按视图自动保存，重启后可继续使用。
- 筛选面板点「应用」即生效并保存。表格底部显示保存状态，视图配置仍可手动重试保存。

## v1.1.5 视图修复与更新红点

- 新建或另存后，表格、顶部视图标签和当前视图名称同步切换。快速切换视图或报表时，各视图保留自己的配置。
- 已应用的筛选、排序和分组在本次运行中切换后仍保留。点击「更新当前视图」可在重启后保留。字段布局按视图自动保存。
- 正式版启动约 5 秒后自动检查更新，运行期间每 6 小时再检查一次。发现新版时，左侧「软件更新」显示红点。

## v1.1.4 移除数量限制并隔离单条错误

- 定时开启和主任务不再有写死的 100 条操作上限，按已保存规则处理全部符合条件的广告。
- 保存规则不再截断保护规则、花费档位、同档条件或白名单，也不再把用户设置的复核次数限制到 100。
- 广告、账户和授权账号完整分页读取；取消 200 页总量限制，检测重复分页和不完整结果。
- 单条广告或账户的接口、权限、格式及请求超时错误记录后跳过，其他广告继续控制。坏记录单独记录，未确认写入先核验，避免重复操作。
- 任务中心和定时开启页显示“不设数量上限”及真实处理数量；保留断网/登录恢复、停止、观察模式和店铺/数据库校验。
- 升级保留本机数据库、规则、视图、登录状态和备份目录。更新前退出其他店铺实例，重开后点击“运行”恢复任务。

## v1.1.2 运行中编辑规则和定时设置

- 控制规则全部内容支持运行中编辑和自动保存，包括保护规则、花费检查点、白名单、复核设置、默认恢复和 JSON 载入。
- 当前轮继续使用开始时的完整配置，保存后的规则从下一轮生效；已发送的广告请求继续核验。
- 定时开启的开关、时间、花费范围、检查窗口和重试间隔支持运行中保存，下一次检查起生效，不需要停止后重新运行。
- 修改不清空已用复核次数和当天已完成的定时记录，避免重复处理。无效草稿不会覆盖上次有效配置。
- 店铺、账户范围、运行模式和主任务采集时区仍需停止后修改。升级保留原数据和配置，重开后手动点击“运行”。

## v1.1.1 启动兼容修复

- 修复部分新电脑打开软件时提示“实例状态暂时无法确认”，导致无法进入首次设置的问题。
- 改进 Windows 本地实例检查，兼容本机连接受限或响应较慢的情况；保留同一店铺和数据库的互斥保护。
- 保留与 v1.1.0 的互斥兼容，现有店铺数据、配置、登录状态和备份目录保持原样。
- 启动检查异常使用准确提示，不再统一显示为“数据未能打开”。

如果 v1.1.0 无法打开，请重新下载最新安装包，退出旧程序后覆盖安装，**无需删除数据目录**。安装后仍需手动点击“运行”。

## v1.1.0 独立店铺实例

- 新增“管理 → 店铺实例”，可创建、打开和重命名实例，一台电脑可同时运行多个店铺。
- 每个实例的登录会话、加密账号密码、规则与白名单、账户选择、任务、表格视图、数据库和备份独立。
- 原有店铺保留为“默认店铺”，沿用原应用目录及自定义存储位置，保留现有数据和配置。
- 新实例首次打开时分别选择数据和备份位置，再自行登录、选择账户和运行；规则从默认设置开始。
- 窗口标题、顶部名称和托盘菜单区分店铺；停止或退出一个实例不影响其他店铺。同一店铺不能由多个实例同时运行。
- 重复打开同一实例会唤起已有窗口。升级后仍需手动运行任务。

## v1.0.6 自定义存储与目录迁移

- 首次启动可分别选择数据目录和备份目录；已有安装继续使用原位置，安装更新不会自动迁移数据。
- 在“数据与设置 → 存储位置”中，停止任务后可分别迁移数据或备份，也可同时迁移。
- 迁移会检查路径、权限及磁盘空间，复制并校验数据库全部表记录、设置和备份文件，全部通过后才切换位置并重新打开软件。
- 原数据库及备份会保留，目标目录已有文件不会被覆盖；目录不可访问时提供找回原数据位置入口。
- 登录会话、加密密码和位置记录继续保存在原应用目录，请保留该应用目录。迁移后仍需手动点击“运行”。

## v1.0.5 视图与白名单改进

- 白名单支持运行中新增、删除、批量删除、撤销和修改备注，保存后下一轮生效。
- 字段显隐、顺序、列宽、冻结和行高按表格及视图独立自动保存，筛选日期、分页和重新打开后保留。
- 每张表只保留一个内置默认视图，自建视图保留且可删除；默认视图也能保存筛选、排序、分组、着色和汇总。
- 在“视图配置”中重命名默认或自建视图，保留原有配置；升级时继承最近保存的旧内置视图字段配置。
- 更新保留本机数据库、规则、视图、账户选择与加密登录设置；更新后仍需手动点击“运行”。

## 主要功能

- 独立桌面运行，支持多个独立店铺实例，每个店铺可管理多个广告账户。
- 观察／操作模式，持续执行广告保护、暂停复核和可选的账户当地时间定时开启。
- 广告明细、账户汇总、操作日志采用本地表格，支持独立视图、筛选、排序、分组、冻结、汇总和完整 CSV 导出。
- 支持托盘常驻、断网恢复、可选本地加密自动登录，以及手动／每日自动备份。
- 重启软件、安装更新或恢复备份后，需要手动启动任务。

## 首次安装

从 [最新正式版本](https://github.com/harmony-s/sc-fb-desktop/releases/latest) 下载 `ShopcityControllerSetup.exe`，关闭旧版后安装。

安装包链接：[下载 Windows 安装包](https://github.com/harmony-s/sc-fb-desktop/releases/latest/download/ShopcityControllerSetup.exe)。

## 后续更新

在软件左侧打开“软件更新”，检查并下载新版本，然后点击“重启安装更新”。软件也会在后台定期检查新版本。

重启安装前会停止广告任务，完成已发送请求的核验。本地数据库、规则、视图和登录会话会保留。更新后需要手动点击运行来继续广告任务。

多个店铺实例共用一个软件版本。v1.1.0 起，安装更新前需先退出其他实例；关闭窗口可能只是收起到托盘，请从其托盘菜单选择“退出当前实例”。当前实例会完成保存、停止和升级前备份后安装，更新后重新打开发起更新的实例。

v0.10.0 及更早版本没有内置更新入口，需要先手动安装一次带更新功能的版本。

## 发布文件

- `ShopcityControllerSetup.exe`：首次安装或手动更新。
- `RELEASES` 和 `XHShopcityController-<版本>-full.nupkg`：软件内置更新使用。
- `SHA256SUMS.txt`：发布文件校验值。

这些文件随 GitHub Release 提供，不存入 Git 文件历史。此仓库不存放使用者的本地广告数据库、登录信息或个人配置。
